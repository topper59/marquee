        Display

        When more than one thing is playing on Plex, the display rotates between the streams; this is how long each one stays on screen.

        The panel is dark outside these hours; “until 12:00 AM” means midnight. Set both to 12:00 AM to keep it on around the clock.

        Home Assistant optional

        Dims the panel while your TV is on.

        On, the panel dims only when the TV is on and the sun has set (using Home Assistant’s sun.sun). Off, it dims whenever the TV is on, day or night.

        The brightness the panel drops to while dimming is active (instead of the normal display brightness).

        Device

        How these settings pages look. It is stored on the display, so every phone or laptop you open them from matches.

        With a password set, this page asks for it before allowing changes. Leave it off on a trusted home network if you prefer.

        Factory reset

        Erases everything on the display — the Plex server, all display settings, the settings password, and the saved WiFi network — and restarts it into first-time setup, exactly as if it had come out of the box. This is the same thing that holding the button on the back for 10 seconds does.

        The display leaves your WiFi and creates its own NowPlaying-Setup network again, so this page will stop working. To set it up once more, join that network from a phone or laptop.

        Only starting over with the settings? — the display keeps its network connection and this page comes back.

        A saved change needs a restart to take effect — use the restart button when ready.
